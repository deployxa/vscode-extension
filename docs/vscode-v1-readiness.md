# V1 readiness

Implemented in the first GUI slice: Home, onboarding, secure account controls, Simple/Advanced mode, project cards, primary deployment actions, workspace linking, recent activity, authoritative progress, friendly success/failure states, logs/diagnosis entry points, and preserved Explorer commands.

Readiness scoring, DNS guidance, typed database metrics/backups/users, Ask Deployxa, and Rich Progress are now integrated through authoritative SDK resources.

Direct folder upload (`deployxa.deployFolderUpload` + `DeployxaClient.uploadProject`) lets vibe coders deploy a local folder without Git or GitHub; the Engine build worker extracts the uploaded archive instead of cloning a repository.

Deferred pending write APIs or dedicated extension-host QA: database mutations, searchable in-editor logs, full environment/domain forms, and complete screenshot automation.
